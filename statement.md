# Project Statement

## Problem Statement

Managing a small college library manually can make it difficult to keep track of books, members, and issued books. Searching records and checking whether a book is available can take unnecessary time when information is maintained only on paper.

The Library Management System provides a simple command-line solution for maintaining basic library records.

## Scope

The project focuses on basic library activities:

- Managing book records
- Managing member records
- Searching for books
- Issuing books
- Returning books
- Showing simple library statistics

The project is intended for a small academic or classroom library and is not designed as a large commercial library system.

## Target Users

- College students
- Small college libraries
- Teachers demonstrating basic Python
- Beginners learning programming

## High-Level Features

1. Book management
2. Member management
3. Book search
4. Book issue and return
5. Library report
6. Text-file data storage
7. Basic validation
